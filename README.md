# MOKKA — Coffee Shop Website Concept

MOKKA is a fictional coffee shop website concept created as a frontend development portfolio project.

## Demo status

This is a non-commercial demo. The business, products, prices, location, opening hours, and contact details shown in the interface are fictional. No orders, payments, bookings, or real customer communications are provided.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Internationalization (English, Polish, Russian)

The project demonstrates responsive UI, reusable components, multilingual interfaces, and frontend development practices.
